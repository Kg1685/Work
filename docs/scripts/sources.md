# Источники к Эпизоду 01 (проверено, не «Пинтерест»)

Правило канала: каждый факт в сценарии имеет источник здесь. Спорное — помечаем как «по одному свидетельству» или выбрасываем.

## Основные (что реально есть в записях)
1. **А. Н. Афанасьев, «Поэтические воззрения славян на природу» (1865–1869)** + «Народные русские сказки» (1855–1863) — леший как «хозяин леса», сюжеты с заведённым путником.
2. **С. В. Максимов, «Нечистая, неведомая и крестная сила» (1903)** — самый читаемый свод бытовых поверий; там же о свисте, о пастушьем договоре.
3. **Д. К. Зеленин, «Очерки русской мифологии» (1916) / «Восточнославянская этнография»** — научная база, «заложные покойники», региональные различия.
4. **В. И. Даль, «Толковый словарь живого великорусского языка» (1863–1866)** — статья «Леший»: «лесной хозяин», прозвища (лешак, лесовик, лесной дядя).
5. **Современная академическая сводка**: «Русская фольклорная демонология» (изд. МИФ; глава о лешем) — цитаты полевых записей (Архангельская губ., Владимирская губ.), правила поведения в лесу. PDF в открытом доступе.
6. **Англоязычные проверяемые переводы**: W. R. S. Ralston, *Russian Folk-Tales* (1873) — если нужна цитата на английском; Project Gutenberg / Sacred-Texts.

## Что НЕ используем как источник
- Статьи-«энциклопедии» вроде world-of-legends, kulturanaroda и Pinterest-подборки — красиво, но без ссылок; годится только как указатель, куда копать.
- «Ведьмак» (Leshen) — исключительно как культурный контекст в финале, не как факт о поверьях.
- Утверждения вида «леший = бог Велес» — это популярная реконструкция, а не зафиксированное поверье. В сценарии подаём как гипотезу исследователей, с оговоркой.

## Факты в сценарии → где подтверждение
| Утверждение | Источник |
|---|---|
| Имя от *les* «лес», не имя а не титул | Даль; этимология |
| В Архангельской губ. «в лесу свистит только леший» | полевая запись, сводка «Русская фольклорная демонология» |
| Не ночевать на росстани (перекрёстке дорог) | там же, полевые записи |
| Просить разрешения, входя в лесную избушку | там же |
| Вывернуть одежду наизнанку / обувь не на ту ногу | Афанасьев; Ralston |
| Пастуший договор: снять крест, хлеб-соль, запреты | Максимов; англ. пересказ у Ralston |
| Сюжет с рукой в расщепленном бревне | Афанасьев (сказочный сюжет, мировое бродячее ядро) |
| «Я такой же человек, на мне только креста нет, меня мать прокляла» | запись Владимирской губ. в сводке |
| Бортничество, дёготь, смола, уголь как лесная экономика | Зеленин; исторические обзоры |
| Гигант в чаще / вровень с травой на поляне | Афанасьев, Максимов |

## Как цитировать в описании ролика
Даём короткий блок «Sources» с 3–4 пунктами (Афанасьев, Максимов, Зеленин + англ. перевод Ralston). Это редкость в нише и работает как сигнал качества для «умного» зрителя.
