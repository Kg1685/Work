# Монтаж: короткий курс на один вечер (CapCut / DaVinci Resolve)

Цель: вы умеете собрать ролик 25–30 мин за 2–3 часа, не зная монтажа. Дальше — только практика.

## 0. Что выбрать
- **CapCut (бесплатно, Windows/Mac/iOS/Android)** — быстрее всего для «костёр + кадры + текст». Начните с него.
- **DaVinci Resolve (бесплатно)** — мощнее, цвет, звук. Переходите, когда упрётесь в CapCut.
- Не платите за Premiere на старте.

## 1. Подготовка проекта (30 мин)
1. Папка на диске: `YT/EP01/{audio, video, music, graphics, export}` — всегда одна схема.
2. Импорт: аудио (ваш готовый WAV), 10–14 видеоклипов, 3–4 эмбиента, лого/шрифт.
3. Разрешение: **1920×1080, 30 fps** для длинных роликов (не 60 — длиннее рендер и больше вес). Вертикаль для шортсов — отдельный проект 1080×1920.
4. Шрифт: один-два на канал (например, Cormorant / EB Garamond для «старины» + чистый sans для правил). Один раз — навсегда.

## 2. Сборка «скелета» (45 мин)
1. Кидаете аудио на таймлайн.
2. Слушаете, ставите **маркеры** (`M` в CapCut / `M` в Resolve) на смысловые блоки из сценария.
3. Под каждый маркер — 1–2 клипа. Правило: **кадр меняется каждые 6–12 секунд**, но медленно (никаких быстрых склеек — это «у костра», а не клип).
4. Движение внутри кадра: медленный зум 105% → 115% за 8–10 сек (эффект «живой картинки»). Один и тот же приём на всём канале = стиль.

## 3. Звук (30 мин) — важнее картинки
1. Голос: нормализация до −16 LUFS.
2. Эмбиент: отдельная дорожка, **−22…−18 dB**, с плавными fade in/out на входах-выходах.
3. Музыка (если есть): −26…−24 dB, и **убирать её под голосом** (ducking, в CapCut — «Auto ducking» или ключевые кадры громкости).
4. Финальная проверка: послушайте в наушниках и в динамике телефона. Если голос «тонет» в телефоне — поднимите 2–3 kHz на голосе.

## 4. Графика (20 мин)
- Карточки правил: текст 60–72 pt, появление fade 0,5 сек, стоит 6–8 сек.
- Нижняя плашка с названием канала — только первые 20 сек и в конце.
- Субтитры: CapCut → «Авто-субтитры» → **обязательно вычитать** (имена собственные он ломает всегда) → экспорт SRT → загрузить в YouTube отдельно (лучше для SEO, чем вшитые).

## 5. Экспорт и загрузка
- Мастер: H.264, 1080p, 30 fps, битрейт 12–16 Mbps, аудио AAC 320 kbps.
- Превью: PNG 1280×720, < 2 MB.
- Загрузка: название → описание (шаблон в `packaging.md`) → превью → плейлист → главы → субтитры → «Не для детей» → **флажок altered/synthetic content** → публикация по расписанию.

## 6. Пять ошибок новичка
1. Быстрые склейки «чтобы не скучали» — в этой нише наоборот.
2. Музыка громче голоса.
3. Вшитые субтитры вместо SRT.
4. Один и тот же клип леса в каждом ролике (YouTube это не любит, зритель тоже).
5. Рендер в 4K на старте — время в никуда, для 1080p телефона разницы нет.

## 7. Что ускорит работу в 3 раза
- Сохранить проект-«болванку» с дорожками, шрифтами, плашками, эмбиентом → каждый новый ролик начинается с копии.
- Шаблон превью в Canva/Photoshop: меняете только текст и фон.
- Список клипов, которые надо найти, я даю заранее по блокам сценария — вы не ищете «что-нибудь красивое» в процессе.
